### Custom trigger

This example demonstrates how to trigger the datepicker from an icon within an input field. You can also type a date directly into the input field, and the datepicker will automatically update to reflect the entered date. The selected date is also updated in the input field. The date format validation is basic, but it can serve as a starting point for building more complex use cases.
